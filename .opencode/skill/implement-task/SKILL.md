# Skill: implement-task

Реализует ровно одну задачу по её самодостаточной карточке
(`docs/specs/NNN-*/tasks/<T#>-<slug>.md`, ADR 0021). Рассчитан на локальную
модель — карточка уже содержит весь нужный контекст, дополнительное чтение
конституции проекта не требуется и не нужно.

## Предусловие

Дана одна карточка со `status: pending` в frontmatter. Если карточки нет —
это не задача для этого скилла: попросить сгенерировать её `decompose-tasks`
(Claude) или передать задачу напрямую Claude.

## Границы контекста — жёстко

- Читать **только**: саму карточку + файлы, которые она явно называет
  (Red/Green/Boundaries пути) + любые файлы, которые понадобится
  прочитать/изменить внутри уже названных в карточке путей.
- **Не читать** `AGENTS.md`, `spec.md`, `plan.md`, другие карточки, другие
  пункты `tasks.md` — карточка самодостаточна по построению; если её не
  хватает, это повод остановиться (см. «Эскалация»), а не искать контекст
  на стороне.

## Цикл

1. **Red.** Написать тест из секции Red карточки (дословно, если код дан
   целиком; иначе — по псевдокоду) по указанному пути. Запустить, убедиться,
   что падает.
2. **Green.** Минимальный код из секции Green, чтобы тест прошёл. Не больше
   того, что описано в карточке.
3. **Refactor.** Только косметика при зелёных тестах — без изменения
   поведения и без выхода за Boundaries карточки.
4. **Acceptance.** Прогнать команду из секции Acceptance карточки дословно.
   Она должна пройти целиком, не только новый тест.
5. **Завершение.** Проставить в frontmatter карточки `status: done`.
   Открыть `tasks.md` фичи (путь — `feature` из frontmatter карточки) и
   отметить соответствующий чекбокс (`- [ ]` → `- [x]`), не трогая
   остальные пункты.

## Явный запрет

- Заводить файлы сверх перечисленных в Red/Green секциях карточки.
- Трогать `proto/`, миграции, `docs/adr/`, `AGENTS.md`/`CLAUDE.md`.
- Брать больше одной задачи за вызов скилла — даже если рядом лежат другие
  карточки со `status: pending`.
- Импровизировать архитектурные решения, которых нет в карточке дословно.

## Эскалация

Если во время выполнения выясняется, что инструкция карточки неполна,
устарела (код разошёлся с тем, что описано в Контексте) или противоречива —
**остановиться**, ничего не коммитить как готовое, явно перечислить, что
именно неясно или разошлось. Это сигнал для `decompose-tasks` (Claude)
перегенерировать карточку, а не повод довыдумывать решение самостоятельно.
