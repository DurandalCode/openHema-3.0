## Порядок

Задачи выполняются сверху вниз. Внутри задачи: сначала падающий тест (red),
затем минимальный код (green), затем рефактор при зелёных тестах.

## Треки и параллельность

Волна 0 — общие примитивы каркаса (`shared/ui`, `widgets/admin-shell`),
от которых зависят все экраны; выполняется последовательно (файлы малы и
частично соседствуют, дробить на треки не даёт выигрыша). Волна 1 —
применение примитивов на конкретных экранах админки: у каждого экрана свои
файлы (`features/*/ui/*`, `app/(admin)/admin/**/page.tsx`), треки не
пересекаются и не ждут друг друга — идут параллельно. Волна 2 — join:
полный прогон тестов, сборка, ручная проверка на нескольких ширинах,
обновление статусов.
