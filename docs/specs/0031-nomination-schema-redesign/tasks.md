## Порядок

Задачи выполняются сверху вниз. Внутри задачи: сначала падающий тест (red),
затем минимальный код (green), затем рефактор при зелёных тестах.

Контрактов и сервера в этом инкременте нет (NFR-1) — волна 0 состоит из

удаление старой композиции трогают файлы всех трёх — отдельная join-волна.
