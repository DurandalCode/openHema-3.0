# Spec: Технические исходы боя

- Статус: draft — пакет для согласования, не разрешение реализации.
- Дата: 2026-09-25
- Источник: M10 / F04 [аудита](../../feedback-audit-2026-09-25.md).
- Решения: D-TECH в [реестре](../../implementation/2026-09-feedback/decisions.md).

## Проблема и акторы

Секретарь должен оформить техническую победу без выдуманного счёта. Организатор должен иметь возможность применить решение о снятии к оставшимся боям участника, включая пары, которые появятся позже. Зритель должен отличать спортивный результат от технического.

## Предлагаемые правила

Это предложения, не ранее согласованные требования. Реализация заблокирована до D-TECH.

- FR-1. Администратор назначает техническую победу выбранной стороне в неначатом или текущем незавершённом бою. Причина обязательна: неявка, травма, дисквалификация, другое; для «другое» требуется пояснение. Уже завершённый результат меняется только через явное переоткрытие с проверкой зависимых боёв.
- FR-2. Технический исход хранится отдельно от счёта. Фактически набранный счёт сохраняется для истории. В групповых показателях этот бой даёт победу/поражение, но не добавляет очков за нанесённые/полученные попадания. На табло явно указано «Техническая победа».
- FR-3. Область действия: один бой, оставшаяся номинация или оставшийся турнир. До массового действия показываются участник, причина, область и список существующих затрагиваемых боёв. Уже завершённые бои не меняются.
- FR-4. Для двух последних областей действует сохраняемое правило: оно применяется также к новым парам после формирования следующих этапов. Повторное выполнение не создаёт повторных результатов. Частично выполненное действие имеет видимый статус и безопасно продолжается.
- FR-5. Если в паре оба участника подпадают под снятие, система не назначает случайного победителя и не продвигает никого автоматически. Показывается конфликт, требующий решения организатора. Двойное поражение и новая схема продвижения не входят в первую версию.
- FR-6. Отключение правила действует только на ещё не обработанные/будущие бои. Уже назначенные результаты перечисляются и не отменяются автоматически. Отмена результата, от которого уже зависит начатый бой, блокируется с понятной причиной.
- FR-7. Технический исход текущего боя подчиняется оглашению 0052: оба экрана удерживают один результат до «Показать следующий». Массовое действие не переключает показываемую пару неожиданно.
- FR-8. Снятие в ростере и технический исход — разные операции. В первой версии правило не меняет автоматически статус бойца или оплату заявки; интерфейс объясняет это различие. Существующее снятие не запускает каскад молча.
- FR-9. Причины и автор изменений доступны организаторам; публично — технический исход без медицинского пояснения/свободного текста.

## Приёмка

- AC-1. Given счёт 4:2, When назначена техническая победа стороне B, Then победитель B, счёт истории 4:2, в рейтинге победа B без очковых показателей этого боя.
- AC-2. Given снятие до старта боя, When назначен исход, Then бой завершён технически без искусственного старта таймера.
- AC-3. Given preview массового действия, When изменился один из боёв, Then конфликт явно виден; новый результат не перезаписан.
- AC-4. Given частично выполненный каскад, When запрос повторён после сбоя, Then применённые результаты не дублируются, оставшиеся продолжаются.
- AC-5. Given активное правило, When следующий этап создаёт новую пару, Then правило применено до возможности начать её обычным образом.
- AC-6. Given оба бойца сняты, When рассматривается их пара, Then продвижение заблокировано и организатор видит конфликт.
- AC-7. Given результат питает уже начатый следующий бой, When запрошено переоткрытие, Then отказ объясняет зависимость и не меняет историю.
- AC-8. Given текущий бой завершён технически, When панель/табло переподключаются, Then оба восстанавливают согласованное оглашение.

## Вне объёма

Автоматическое дисциплинарное производство, удаление истории, пересчёт сыгранной сетки, изменения оплаты, двойное техническое поражение. Эти ограничения требуют подтверждения D-TECH, а не скрытого сокращения M10.
