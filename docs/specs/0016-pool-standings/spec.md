# Spec: Статистика и итоговая таблица пула (pool standings)

> Артефакт SDD (ADR 0008). Описывает **ЧТО и ЗАЧЕМ**. Без технологий, API и
> схем БД — только предметная область. Реализация — в `plan.md`.

- Статус: done
- Дата: 2026-08-02

## Проблема

Жизненный цикл пула сейчас останавливается на исполнении отдельных боёв
(спека 0013): статус пула автоматически становится «завершён», когда все его
бои проведены, но дальше с результатом ничего не происходит — ни секретарь,
ни зритель не видят сводных итогов пула (кто сколько боёв выиграл, сколько
очков набрал и пропустил), только отдельные бои по одному. Чтобы довести
жизненный цикл пула до конца, нужна итоговая таблица результатов с местами
бойцов — она же станет опорой для будущего перевода бойцов в следующий раунд
или плейофф (сам перевод — отдельный, следующий инкремент).

## Акторы

- **admin** (секретарь) — видит итоговую таблицу на странице управления пулом
  номинации; использует её для собственных решений по дальнейшим раундам
  (сам процесс перевода — вне скоупа этой фичи).
- **guest** (зритель) — видит ту же таблицу на публичном экране номинации
  (спека 0011/0014), обновляется вживую по мере проведения боёв.

## Пользовательские сценарии

1. Как **admin**, я хочу видеть итоговую таблицу пула (место, боец, победы,
   ничьи, поражения, набранные и пропущенные очки), чтобы понимать
   расстановку сил без пересчёта боёв вручную.
2. Как **admin**, я хочу видеть таблицу уже по ходу боёв пула, а не только
   когда пул полностью завершён, чтобы следить за турниром в реальном
   времени.
3. Как **guest**, я хочу видеть ту же таблицу на публичном экране номинации,
   обновляющуюся без перезагрузки страницы, чтобы следить за результатами
   пула.

## Требования

- FR-1: Система вычисляет для каждого бойца пула статистику по завершённым
  боям этого пула: число побед, число ничьих, число поражений, сумму
  набранных очков, сумму пропущенных очков. Бои, которые не начаты или ещё
  идут, в статистику не входят (учитываются только зафиксированные
  результаты).
- FR-2: Система ранжирует бойцов пула в итоговой таблице по правилу (по
  убыванию значимости критерия):
  1. число побед — больше выше;
  2. сумма набранных очков — больше выше;
  3. сумма пропущенных очков — меньше выше.
- FR-3: Бойцы, полностью равные по всем трём критериям FR-2, делят одно
  место (стандартное спортивное ранжирование: 1, 2, 2, 4 — а не 1, 2, 2, 3).
- FR-4: Ничья засчитывается обоим бойцам боя как отдельный счётчик — не как
  победа и не как поражение ни одному из них; на ранжирование (FR-2) прямо
  не влияет, но очки ничейного боя всё равно суммируются в набранные/
  пропущенные каждого бойца.
- FR-5: Итоговая таблица пула доступна admin на странице управления пулом
  номинации.
- FR-6: Итоговая таблица пула доступна гостю на публичном экране номинации
  (спека 0011/0014) и обновляется в реальном времени по тому же живому
  каналу, что и остальные данные номинации (спека 0014), без перезагрузки
  страницы.
- FR-7: Таблица показывается начиная с первого завершённого боя пула (пул в
  исполнительной фазе «идёт»/«завершён», спека 0011). У пула без ни одного
  завершённого боя («не готов»/«готов»/«готовится к запуску») блок таблицы
  не отображается — таблица из одних нулей до начала боёв неинформативна.
- FR-8: Таблица — производная от текущего состояния боёв пула, не хранит
  собственной копии результата: любое изменение уже зафиксированного счёта
  (например, повторное открытие завершённого боя и правка счёта, спека 0013)
  немедленно отражается в пересчитанной таблице без отдельных действий
  администратора.

## Критерии приёмки

- **AC-1**
  - Given: пул с 4 бойцами, все 6 боёв раунд-робина завершены с разными
    исходами
  - When: admin или guest открывает итоговую таблицу пула
  - Then: строки отсортированы по местам согласно FR-2/FR-3; каждая строка
    показывает победы/ничьи/поражения/набранные/пропущенные очки, посчитанные
    по правилу FR-1

- **AC-2**
  - Given: пул, где завершён только один бой из шести (остальные не начаты)
  - When: admin или guest открывает итоговую таблицу пула
  - Then: таблица отображается (не скрыта, т.к. есть завершённый бой);
    у участвовавших в завершённом бою бойцов есть ненулевая статистика по
    этому бою, у остальных — нули

- **AC-3**
  - Given: два бойца пула после всех боёв имеют одинаковое число побед,
    одинаковую сумму набранных и одинаковую сумму пропущенных очков
  - When: строится итоговая таблица
  - Then: оба бойца получают одно и то же место; следующий за ними по
    результату боец получает место, увеличенное на число бойцов в этой
    группе равенства (пример: 1, 2, 2, 4)

- **AC-4**
  - Given: бой пула завершается вничью (равный счёт, спека 0013)
  - When: строится итоговая таблица
  - Then: обоим бойцам этого боя засчитывается по одной ничьей (не победа и
    не поражение ни одному); очки боя суммируются в набранные/пропущенные
    очки каждого как обычно

- **AC-5**
  - Given: секретарь повторно открывает уже завершённый бой пула, правит
    счёт и завершает заново (спека 0013, Reopen → Score → Finish), либо
    сбрасывает начатый бой (Reset)
  - When: итоговая таблица пула запрашивается/обновляется после этого
  - Then: таблица отражает актуальный счёт без отдельного действия
    администратора по «пересчёту» — она всегда производная от текущего
    состояния боёв (FR-8)

- **AC-6**
  - Given: пул без ни одного завершённого боя (статус исполнения «не готов»,
    «готов» или «готовится к запуску»)
  - When: admin или guest открывает страницу с пулом
  - Then: блок итоговой таблицы не отображается (FR-7)

- **AC-7**
  - Given: зритель открыл публичный экран номинации с таблицей активного
    пула
  - When: секретарь завершает ещё один бой этого пула
  - Then: таблица на экране зрителя обновляется без перезагрузки страницы
    (тот же живой канал, что и у остального экрана, спека 0014)

## Вне скоупа

- Явное admin-действие «завершить пул» — статус пула остаётся полностью
  вычисляемым, как сейчас (спека 0011/0013): эта фича не меняет модель
  завершения пула, только добавляет статистику поверх неё.
- Перевод/сид бойцов в следующий раунд или плейофф по итогам таблицы —
  будущий инкремент. Эта фича только считает и показывает место бойца в
  своём пуле, никак не запускает и не готовит технически сам переход (нет
  RPC/данных под конкретную схему следующего раунда).
- Сводные таблицы, сравнивающие бойцов из разных пулов одной номинации между
  собой (например, «лучшие вторые места» для посева плейоффа) — только
  внутрипуловые итоги.
- Итоговая таблица/места на табло арены (scoreboard) — уже осознанно
  оставлено вне скоупа спекой 0015, остаётся вне скоупа и здесь.
- Экспорт, печать или иной вывод таблицы за пределы экранов admin/guest.
