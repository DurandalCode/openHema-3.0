# T1 — `.env.example`: задокументировать `PREPROD_MODE`/`REGISTRATION_DISABLED`

> Артефакт ADR 0021. Самодостаточная карточка: исполнитель работает
> **только** с этим файлом и файлами, которые он явно называет — не
> заглядывает в `AGENTS.md`, `spec.md`, `plan.md` или другие задачи.

## Цель

`.env.example` должен объявлять два новых флага веб-процесса —
`PREPROD_MODE` и `REGISTRATION_DISABLED` — пустыми (= выключено) по
умолчанию, тем же стилем, что уже принят в этом файле.

## Контекст

Конец файла `/Users/danilaorehov/hema/.env.example` сейчас:

```
# ── Web / BFF ─────────────────────────────────────────────────
# Адрес Go-сервера, куда BFF ходит по gRPC/Connect
SERVER_GRPC_URL=http://localhost:8080
# Порт Next.js
WEB_PORT=3000
```

Образец уже существующего в этом файле флага «пусто = легально выключено»
(секция «Учётка, почта и файлы») — ориентир на стиль комментария и формат,
не готовый текст для копирования один в один:

```
# Каталог локального тома файлового хранилища (регламент и эмблема
# турнира, ADR 0019). Пусто — легальная конфигурация (NFR-4): хранилище
# выключено, загрузка файлов недоступна, регламент/эмблема остаются
# доступны по внешней ссылке.
FILE_STORAGE_DIR=
```

## Red — тест первым

Нет теста — конфигурационный файл, не исполняемый код. Готовность
проверяется по Acceptance ниже.

## Green — минимальная реализация

Путь: `/Users/danilaorehov/hema/.env.example`

В конец файла добавить новую секцию с двумя пустыми переменными и
комментарием над каждой в стиле образца выше:

- `PREPROD_MODE` — что это (гейт публичных страниц/данных для анонимов),
  что значит включение (строка `true`), что пусто/что-либо ещё = выключено.
- `REGISTRATION_DISABLED` — что это (пауза самостоятельной регистрации),
  независимость от `PREPROD_MODE`, то же правило «пусто = выключено».

Формулировки — свои, по смыслу двух предложений из «Цель» и по стилю
образца из Контекста, а не копия комментария `FILE_STORAGE_DIR`.

## Acceptance

Команда: `grep -c '^PREPROD_MODE=' .env.example && grep -c '^REGISTRATION_DISABLED=' .env.example`

Критерий: обе команды возвращают `1` (строка с пустым значением, с
комментарием над ней). Остальной файл не менялся.

## Boundaries

- Не создавать файлы сверх `.env.example`.
- Не трогать: остальные секции `.env.example`, `docker-compose.yml`,
  Go-код, `web/src/**`.
- Если строки `PREPROD_MODE=`/`REGISTRATION_DISABLED=` уже есть в файле —
  остановиться, ничего не менять, сообщить об этом.
