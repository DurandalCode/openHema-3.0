## Порядок

Задачи выполняются сверху вниз. Внутри задачи: сначала падающий тест (red),
затем минимальный код (green), затем рефактор при зелёных тестах.

Контрактов (proto/sql) в инкременте нет — волна 0 отсутствует, работа
начинается сразу с двух дизъюнктных web-треков.

функций — на join-волне они заменяются реальными импортами.
