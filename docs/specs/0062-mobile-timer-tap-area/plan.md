## Обзор решения

Только web, один компонент: `widgets/arena-console/bout-timer-strip.tsx`
(`BoutTimerStrip`, спека 0045, T4). Левая часть полосы (раунд/статус/время) и
нынешняя маленькая кнопка «Старт/Пауза» объединяются в один нативный
`<button>` на всю ширину полосы, кроме «⋯». Логика старта (`useStartBout` →
`controls.start`, FR-2/FR-3) остаётся прежней — меняется только разметка.
Колонка `TimerControls` (≥`md`) и `BoutPanelView` не трогаются.

## Web (FSD + BFF)

- BFF: без изменений.
- `widgets/arena-console/bout-timer-strip.tsx`:
  - Корень — `Row` с `items-stretch`: слева `<button type="button">`
    (`flex-1 min-w-0 min-h-20`), справа `SheetTrigger` «⋯» той же высоты
    (`self-stretch`, отдельный элемент — не вложен в область-кнопку, вложенные
    `<button>` невалидны, FR-6).
  - Область-кнопка: `aria-label={running ? "Пауза" : "Старт"}` (FR-7 — имя не
    собирается из времени/статуса); `onClick={running ? controls.pause :
    handleStart}`; `disabled={!running && startBout.isPending}` (FR-3).
  - Содержимое: строка «Раунд N · статус» + `TimerDisplay size="strip"` и
    крупная подпись действия «Старт»/«Пауза» (`aria-hidden`, имя уже в
    `aria-label`) с иконкой ▶/❚❚ (FR-5).
  - Цвета состояний (FR-5): красится вся область-кнопка: не идёт —
    `bg-emerald-600` «▶ Старт», идёт — `bg-slate-800` «❚❚ Пауза»; текст белый,
    фаза концовки — `amber-300` (читается на тёмном). `active:brightness-90`,
    `disabled:opacity-60`.
  - `touch-manipulation` — без задержки двойного тапа на мобильных браузерах.
  - Убрать `max-[340px]:flex-wrap` у старой разметки: область-кнопка сама
    ужимается (`min-w-0`, `truncate` у строки раунда/статуса).

## Тестирование

- Web (Vitest, `bout-timer-strip.test.tsx`), существующие кейсы по
  `getByRole("button", { name: "Старт" | "Пауза" })` остаются валидными
  благодаря `aria-label`. Новые:
  - клик по элементу времени (`[data-timer-status]`) запускает таймер (AC-1);
  - клик по времени при `RUNNING` — пауза (AC-2);
  - область-кнопка недоступна, пока начинается бой (AC-3, уже есть — проверить);
  - клик по «⋯» не вызывает `start`/`pause` (AC-5);
  - область-кнопка имеет класс минимальной высоты `min-h-20` (AC-6; jsdom не
    меряет layout, проверяем контракт класса);
  - имя кнопки ровно «Старт»/«Пауза», а не текст времени (FR-7).
- `bout-panel-view.test.tsx` — прогнать, AC-7 (планшетная колонка) покрыт
  существующими тестами видимости.
