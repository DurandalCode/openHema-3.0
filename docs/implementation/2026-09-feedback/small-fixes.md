- Статус: draft, пакет для согласования; реализация не начата.
- Дата: 2026-09-25.
- Источник: [аудит](../../feedback-audit-2026-09-25.md).

Это задачи вне реализаций 0052–0060. Новые UI-удобства не объявляются
нарушением прежнего контракта. Каждый кодовый инкремент: воспроизводящий
тест → минимальная реализация → регрессии. QA-задача может закончиться
подтверждением исправности без нового кода и бессмысленного дублирования тестов.

переводит конкретную задачу в spec → plan → tasks до реализации.
