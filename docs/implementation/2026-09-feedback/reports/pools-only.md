# S-POOL / SF-02 — фильтр статуса пулов

- База: `675bf0b3426ddceff4257d571a21ffb8e53cb8bf`.
- Ветка: `feedback/pools-only`.
- Решение: `A-POOLS` (подтверждено пользователем).
- Область: `web/src/features/pool-seating/ui/pool-seating.tsx` и тест рядом.

## Сделано

- На свободной арене выбор пула открывается с режимом «Незавершённые».
  Рядом доступны «Все» и «Завершённые». Статус сопоставляется с
  `Pool.status`, а не со статусом фиксации этапа.
- Фильтр статуса работает вместе с существующим фильтром номинации.
  Завершённый непосаженный пул остаётся доступным для повторной постановки
  через «Завершённые» или «Все», с прежней серверной проверкой.
- Карточка показывает статус и переносит длинное название. Пустой результат
  фильтров объясняется отдельно от случая, когда готовых пулов вообще нет.
- Тесты покрывают начальный выбор, все три режима, комбинацию фильтров,
  постановку завершённого, обновление статуса после нового ответа API,
  длинное название и обе пустые выборки. Сначала новые тесты падали на
  отсутствующем фильтре, после реализации стали зелёными.
