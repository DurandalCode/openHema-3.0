# B03 / M09 — геометрия таймера арены

- Трек: `timer-layout-only`, часть T14 / AC-9 спеки 0052.

- Ветка: `feedback/timer-layout-only`.
- Продуктовое решение: A-TIMER — обрезаются сотые на экране арены; формат остаётся `MM:SS.hh`.

## Изменение

`TimerDisplay` в полной панели теперь ограничивает размер шрифта шириной
`TimerControls`, а не breakpoint окна. Контейнерную ширину задаёт сама колонка,
поэтому `60:00.00` целиком помещается в 300 px колонку режима боя. В режиме
управления карточка может сжиматься на узком окне; длинная кнопка смены сторон
переносит текст. Мобильная полоса таймера ниже 340 CSS px переносит часы и
кнопки на дополнительные строки без их обрезания. Арифметика и формат времени,
источник таймера, команды, API и жизненный цикл боя не менялись.

## Проверка

Сначала в локальном браузерном fixture с настоящими `TimerDisplay`,
`TimerControls` и `BoutTimerStrip` воспроизведено переполнение: при 768 CSS px
в колонке боя правый край текстового фрагмента `10:00.00` был 595.6 px, а
внутренний край колонки — 518 px (на **77.6 px** за пределами). После правки
прогнано **54 браузерных случая**: ширины 360, 390, 639, 640, 767, 768,
1023, 1024, 1280 px × эквиваленты масштаба 100%/200% × `1:30.00`,
`10:00.00`, `60:00.00` (максимум настройки арены — 3600 с). Для видимого
режима управления и полной/мобильной панели измерены реальный DOM-текст,
внутренние края контейнеров, границы действий и локальная прокрутка блока:
**0 нарушений**. Например, при 768 px `60:00.00` в колонке боя остаётся
37.6 px до правого края.

## Ограничения и передача

Браузерная матрица запускалась на временном тестовом маршруте с настоящими
компонентами и CSS приложения, а не на авторизованной странице живой арены.
У координатора остаётся финальная визуальная приёмка реального экрана с
тестовой ареной после объединения веток. При эквиваленте 360/390 физических
px и 200% временный маршрут показал отдельное переполнение общей гостевой
шапки (`Войти` / `Регистрация`); сами блоки таймера в этих случаях не
переполняются. Шапка вне этого трека, её не меняли.

Миграций, изменений контрактов и новых зависимостей нет. Сервер и БД для
этой геометрической правки не запускались.
